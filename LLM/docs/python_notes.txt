Python 列表推导式：
语法格式为 [表达式 for 变量 in 可迭代对象 if 条件]。
例如 [x*2 for x in range(10) if x % 2 == 0] 会得到 [0, 4, 8, 12, 16]。

Python 装饰器：
装饰器是一个接受函数并返回函数的可调用对象。
常见用途：日志记录、性能计时、权限校验、缓存。
使用 @decorator 语法糖，等价于 func = decorator(func)。

Python 生成器：
用 yield 关键字定义，惰性求值，节省内存。
适合处理大数据集或无限序列。
生成器表达式用圆括号：(x*2 for x in range(10))。

Python GIL：
全局解释器锁，同一时刻只有一个线程执行 Python 字节码。
CPU 密集任务用多进程，IO 密集任务用多线程或协程。
